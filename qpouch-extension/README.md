# QPouch - community wallet for QMS Testnet (unofficial)

## Install (developer mode)
1. `ethers.umd.min.js` (ethers v5.7.2) is already bundled in this folder. Nothing to download.
2. Open chrome://extensions, enable Developer mode, click Load unpacked, choose this folder (the one containing manifest.json).
3. Create or import a wallet from the toolbar icon. On a dApp, choose "QPouch" or the injected/browser wallet option.

Supports QMS Testnet (chain 19480) only. Unlock once; locks after 1 hour idle or when the browser closes.
Unofficial and not independently audited. Do not use with real funds.
