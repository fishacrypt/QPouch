# QPouch
QPouch is a community-built, self-custody browser wallet for the QMS
Testnet. It lets users create or import a wallet, connect to
decentralised applications, and sign testnet transactions.
QPouch is an unofficial testnet project. It is not independently audited
and should not be used with real funds.
Features
- Self-custody: Wallet keys are encrypted on the user's device.
- Wallet management: Create a wallet or import an existing one.
- dApp connections: Connect to supported decentralised applications
  through the QPouch or injected-wallet option.
- QMS Testnet support: Supports chain ID 19480.
- Testnet interactions: Sign transactions such as sending a GM message
  or deploying a small test contract.
Browser Support
QPouch is designed for Chrome, Brave, Edge, and other Chromium-based
browsers.
Installation
1. Download the QPouch ZIP file from the official
   website.
2. Extract the ZIP file into a folder on your computer. Keep this
   folder after installation.
3. Open chrome://extensions in your browser.
4. Enable Developer mode.
5. Select Load unpacked.
6. Choose the extracted folder containing manifest.json.
7. Pin QPouch from the browser's extensions menu for easy access.
Using the QMS Testnet
1. Open QPouch and create a wallet or import an existing one.
2. Get test QMS from the QMS Testnet
   faucet.
3. Connect QPouch to a compatible dApp.
4. Review and sign testnet transactions when prompted.
Test QMS is intended for testnet use and has no guaranteed monetary
value.
Security
- Keep your recovery phrase and private keys secret.
- Download QPouch only from a source you trust.
- Review transaction details before signing.
- Use a separate test wallet for testnet activities.
- Do not use QPouch with real funds. The project is unofficial and has
  not been independently audited.
