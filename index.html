InstallFour steps to get running.
01

Download the file

Click Download to save the .zip to your computer.

02

Unzip it

Extract the zip into a folder you'll keep. Don't delete it after installing.

03

Open extensions page

Go to chrome://extensions and switch on Developer mode in the top right.

04

Load unpacked

Click Load unpacked, select the folder containing manifest.json, then pin QPouch from the puzzle icon.
